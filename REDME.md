Personal Expense Tracker
Project Description
This is a simple Python program that allows a user to enter expenses, view the expenses entered, and calculate the total amount of expenses.

Initial Version
The initial version of the program includes the following features:

Allows the user to enter an expense amount
Stores expenses in a list
Displays all expenses entered
Calculates and displays the total expenses
Uses a menu that repeats until the user chooses to exit
Allows the user to exit the program
How to Run the Program
Make sure Python is installed.
Open the project folder in Visual Studio Code.
Open main.py.
Run the Python program.
Choose an option from the menu and follow the prompts.
